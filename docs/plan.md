# 轻舟浏览器（LiteSail Browser）项目计划文档

> 文档版本：v1.0  
> 项目代号：LiteSail  
> 项目定位：自用、轻量、高性能的 Android 浏览器  
> 技术路线：Kotlin + Android 原生 View 体系 + 系统 WebView  
> 建议包名：com.yourname.litesail  
> 文档用途：个人开发计划、任务拆解、验收参考

---

## 1. 项目背景

日常手机浏览器广告多、功能臃肿。本项目目标是开发一个仅给自己使用的 Android 浏览器，强调：

- 轻量：APK 体积尽量小，不引入重型浏览器内核；
- 高性能：冷启动快、页面加载正常、多标签不卡顿；
- 纯净：无广告、无多余推荐、无账号体系；
- 隐私：提供隐私模式，关闭后清理浏览数据；
- 可控：代码和功能完全按个人习惯定制。

---

## 2. 项目目标

### 2.1 核心目标

实现一个可日常使用的 Android 浏览器，支持：

1. 前进、后退；
2. 回到首页；
3. 多标签页管理；
4. 隐私模式；
5. URL 输入与搜索；
6. 基础刷新、停止加载；
7. 浏览历史与首页配置；
8. 关闭标签页时释放 WebView 资源。

### 2.2 非目标

首版暂不追求：

- 跨平台；
- 账号同步；
- 扩展插件体系；
- 复杂广告拦截规则订阅；
- 重型第三方浏览器内核；
- 云同步、书签云备份；
- 桌面端版本。

## 3. 技术栈

| 模块         | 选型                                                      |
| ------------ | --------------------------------------------------------- |
| 开发语言     | Kotlin                                                    |
| UI           | Android 原生 View + XML + ViewBinding                     |
| 浏览器内核   | 系统 WebView                                              |
| 多标签       | Fragment / 自定义 ViewGroup 管理多个 WebView              |
| 数据存储     | SharedPreferences + Room（可选）                          |
| 隐私清理     | CookieManager、WebStorage、WebViewDatabase、clearCache 等 |
| 构建工具     | Gradle + R8 代码压缩                                      |
| 最低版本建议 | minSdk 26 或 28，按自用设备决定                           |
| 目标版本     | 当前主流 targetSdk                                        |

### 3.1 技术路线说明

采用系统 WebView 的原因：

- 不增加 APK 体积；
- 系统组件，启动和渲染性能足够日常浏览；
- 主流 Android 设备 WebView 可独立更新；
- 对新闻、博客、论坛、文档、普通 Vue/React SPA 页面具备可用性；
- 相比 GeckoView，不增加几十 MB 体积和额外启动开销。

## 5. 关键设计

### 5.1 多标签设计

- 每个标签对应一个 WebView 实例；
- 使用 `TabManager` 统一管理标签列表；
- 标签数量建议上限：6～8 个；
- 非活动标签超过一定时间后销毁 WebView，仅保留 URL、标题、滚动位置；
- 切换回已销毁标签时重建 WebView；
- 关闭标签时调用：
  - `webView.stopLoading()`
  - `webView.loadUrl("about:blank")`
  - `webView.clearHistory()`
  - `webView.removeAllViews()`
  - `webView.destroy()`

### 5.2 隐私模式设计

首版采用“会话结束清理”策略：

- 隐私标签不写入浏览历史；
- 关闭隐私标签或退出隐私模式时清理：
  - Cookie；
  - WebStorage；
  - 表单数据；
  - 缓存；
  - 浏览历史；
- 使用独立标签列表管理隐私标签；
- 注意：Android 系统 WebView 的部分数据存储是进程级/全局的，完全强隔离有限。自用场景下以“关闭后清理 + 不记录历史”为主。

### 5.3 返回键逻辑

优先级：

1. 当前 WebView 可后退：执行 `goBack()`；
2. 否则若存在多标签：切换到上一个标签或显示标签页；
3. 否则退出应用。

### 5.4 性能策略

- 限制同时存活的 WebView 数量；
- 非活动标签延迟销毁；
- 首页可预加载，但避免预加载过多标签；
- 避免在滚动时执行重逻辑；
- Release 开启 R8 和资源压缩；
- 不引入不必要的大型依赖。

- [ ] Release APK 体积控制在 5MB 左右或更低；

- [ ] 6～8 个标签切换不崩溃；
- [ ] 关闭标签后内存可释放；
- [ ] 滚动基本流畅。

### 8.3 功能

- [ ] 前进、后退、刷新、停止可用；
- [ ] 回到首页可用；
- [ ] 多标签新建、切换、关闭可用；

## 9. 风险与应对

| 风险                  | 影响              | 应对                                            |
| --------------------- | ----------------- | ----------------------------------------------- |
| 系统 WebView 版本过旧 | 个别 SPA 页面异常 | 自用设备确认 WebView 版本；必要时加版本检测提示 |
| 多 WebView 内存占用高 | 卡顿或崩溃        | 限制标签数；非活动标签销毁重建                  |
| 隐私数据全局存储限制  | 隔离不彻底        | 关闭时主动清理；文档记录边界；后续评估增强方案  |
| 下载/权限复杂         | 功能延期          | 首版可只支持系统浏览器打开下载链接              |
| 广告拦截误杀          | 页面异常          | 首版不做或只做简单域名黑名单                    |
| 范围膨胀              | 延期              | 严格按 MVP 优先，增强功能后置                   |

## 11. 版本计划

### 11.1 v0.1.0 原型

本轮止于单标签浏览，不进入多标签、隐私模式或设置阶段。原型采用 `com.joel.litesail`，最低支持 Android 8.0（API 26），默认首页和搜索引擎均为百度。

- 单标签 WebView；
- 地址栏输入网址或搜索词；
- 加载首页、打开网页链接；
- 前进、后退、刷新和停止加载。

### 11.2 v0.5.0 可用版

- 多标签；
- 标签切换；
- 基础设置；
- 返回键逻辑。

### 11.3 v1.0.0 自用版

- 隐私模式；
- 资源回收；
- 体积与性能优化；
- 自用签名 APK。

### v1.1.0 增强版

- 书签；
- 历史；
- 简单广告拦截；
- 下载支持。

- 首版优先保证“能日常用”，不要过度设计；
- 每个阶段完成后安装到真机验证；
- 隐私清理必须真机验证；

- 如果后续遇到特定 SPA 页面异常，先记录 WebView 版本和页面地址，再决定是否做兼容处理。
